# 🍕 Bingen Pizza & Burger | Artesanal & Wood-Fired

Website moderno, responsivo e de alta performance desenvolvido para a **Bingen Pizza & Burger**, pizzaria artesanal e hamburgueria premium situada em Bingen, Petrópolis - RJ.

![Preview](assets/images/hero-bg-image19.png)

---

## 🚀 Sobre o Projeto

O projeto foi construído com design refinado, animações suaves e foco na experiência do usuário (UX/UI), apresentando os produtos de alta gastronomia, forno a lenha, ambiente acolhedor e sistema de pedidos via WhatsApp / Delivery.

### 🌟 Destaques & Páginas

- **Página Inicial (`index.html`)**:
  - Hero section atmosférico com efeitos visuais e identidade da marca.
  - Carrossel e destaques de pizzas napolitanas e burgers artesanais.
  - Depoimentos de clientes e integração com delivery.
  
- **Cardápio Interativo (`cardapio.html`)**:
  - Filtros dinâmicos por categoria (Pizzas Clássicas, Especiais, Burgers, Bebidas, Sobremesas).
  - Modal de detalhes de itens com personalização e cálculo dinâmico.
  - Integração para envio direto de pedidos ao WhatsApp da pizzaria.

- **O Restaurante (`restaurante.html`)**:
  - História da casa, tradição da massa de fermentação lenta (48h).
  - Detalhes do forno a lenha italiano e ingredientes selecionados.
  - Formulário interativo para reserva de mesas.
  - Galeria de fotos do ambiente e localização interativa com mapa.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível e otimizada para SEO.
- **CSS3 Vanilla & Flexbox/Grid**: Design responsivo, variáveis CSS, microinterações e estética dark premium.
- **JavaScript Moderno (ES6+)**: Lógica interativa de cardápio, carrinho, modais e validação de reservas.
- **Google Fonts**: Tipografias personalizadas (*Anton*, *Barlow Condensed*, *Bree Serif*, *Inter*, *Poppins*).

## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/CanedoDev/pizza-bingen-delivery-system.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd pizza-bingen-delivery-system
   ```

3. Abra o arquivo `index.html` em qualquer navegador moderno ou utilize a extensão **Live Server** no VS Code.
